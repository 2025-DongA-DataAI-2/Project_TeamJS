사용한 라이브러리 및 활용 데이터셋, 분석 방법

kdrama.csv를 기반으로 데이터 구조를 확인하고 전처리 후, 특정 시기별 장르 선호도를 도출하여 시각화했다.

환경 및 데이터

라이브러리
numpy, pandas, matplotlib
프로그램
Python, HTML/CSS, JavaScript
데이터셋
kdrama.csv
numpy pandas matplotlib HTML/CSS JavaScript

분석 방법

  1. kdrama 데이터셋의 크기, 컬럼, 정보 확인
  2. 표본이 적어 결과에 유의미한 영향을 주지 못하는 2003~2009 데이터 제외
  3. 특정 시기별 데이터 및 선호도 컬럼 도출
  4. 분석한 컬럼 기반 데이터 시각화
  5. 결론 도출
